This tool reads and renames documents in the Upperform SharePoint library. It is not public.

Organise the document library

Reads the SharePoint library, works out what each file should be called and where it belongs, and shows you the list. Nothing is renamed or moved until you choose it.

Take a look

This opens each document, works out a name from what is inside it, and checks that name against the convention. It takes about a minute. Nothing changes yet.

Settings
Which library to look at
Paste the address straight from your browser — the whole thing, exactly as it appears — and the site and library are read out of it. Everything in that library is read; nothing outside it is touched. Look again after changing this. This copy is fixed to one library and cannot be pointed elsewhere.
Include Power BI reports
A .pbix is referenced from outside the library by whatever dataset or refresh schedule was built from it, and neither the library nor the file can see that. This covers filing them as well as renaming them — a move changes the path exactly as a rename does. Turn it off to leave the reports, and the workbooks they read, exactly where and as they are.
Read what is inside each document
With this on, Office files are opened on the server and only their text is sent for naming. With it off, names are worked out from file names, folders and kinds alone, and nothing from inside a document leaves the tenant.
Most changes in one run
A ceiling on how much can happen at once, so a run stays small enough to check by eye and undo by hand. It can be lowered here but not raised past what the deployment allows.
At most this many new folders
How much structure one run may invent. Lower it to keep the shape of the library closer to what it already is.
A new folder must hold at least
A folder holding one document is the pile it came from with an extra click in front. Raising this makes fewer, fuller folders — it can be raised here but not lowered.
When a document does not say its status
Every name ends in a status. Draft is the weakest claim, so it under-states rather than over-states. Choosing Do not guess leaves any document that does not say so alone entirely.

What gets carried out

Nothing, until you tick it.

Renaming a document, moving one, creating a folder and renaming a folder are four separate permissions. Each is granted by what you select on the review page, for that run alone — never by a setting here, and never carried into the next run. It is why looking at the library is always safe.
