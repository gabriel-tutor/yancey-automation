The library is already organised. That is the demo — not a rename you stage, but a result you can stand behind, with every change traceable back to the name it arrived under.

Where things stand

This changes what the meeting is. An earlier version of this runbook was written for a demo where nine documents were held back so he could watch them be renamed live. Those were applied on 3 September, so there is nothing left to hold back — a run today reports all documents already follow the convention and offers no changes.

That is the stronger position. He is not being asked to imagine the tool working; he is being shown a finished library and the record of how it got there. Lead with the result, then show the tool that keeps it that way.

Some renames are still pending. The table below lists them. This runbook was built when they were, so the four acts assume he will see changes offered. Read the pending table before the meeting.

Before he arrives

  • Open the page and sign in, so the passcode is not being typed in front of him.
  • Press Look again once and let it finish. It takes about a minute, and doing it now means the first thing he sees is not a spinner.
  • Decide which demo you are giving — the finished library (nothing to prepare) or live action (see below; it needs five minutes of setup first).
  • Have this page open on a second screen or a phone.
  • Check the settings panel is showing the values you expect, and that Carried out reads off. It should. That is the point.

If you want it to do something live

A finished library has nothing to offer, so if he wants to watch it work you have to give it something to work on. There are two ways, and only one of them is a good idea.

Add a few documents — do this

Drop two or three files with ordinary, untidy names into the library shortly before the meeting. This is not a trick; it is the actual use case. Documents arrive named badly, and the tool's job is ongoing hygiene rather than a single clean-up.

  • Use real working documents if you have them, or copies with names of the kind the library used to be full of — a bare description, no project, no date, no status.
  • Put them in Resources and References, where an unfiled document would normally land.
  • Press Look again. They will be the only things offered, so the review stays short enough to read aloud.
  • Tick them, carry them out, and the library is tidy again by the end of the call.

It shows more this way, not less. A run against a clean library that finds two new arrivals and names them is the tool doing its actual job. A staged before-and-after is a screenshot he could have been sent.

Rename the finished ones back — do not do this

The record below is complete enough to reverse every change, and the workflow has a revert setting that lifts the convention check so an untidy name can be restored. It is written down because it exists, not because you should use it.

Four of these are Power BI reports. A .pbix is referenced by path wherever it is published or set to refresh, and nothing inside the library shows that. Renaming them back and forward again means two more breakages of live references, for the sake of theatre. Add new documents instead.

The questions he will ask

Can you undo it?

Yes, and completely — every document in the library traces back to the name it arrived under. Say the number out loud; it is the most convincing thing in this document. Do not say the undo is automatic: it is a recorded list that is replayed deliberately, which is the point.

What if it renames something it should not?

It cannot rename a Power BI report, or a workbook a report actually reads — it opens each .pbix, reads the Power Query text inside, and refuses anything the report names, quoting the query. And nothing is applied at all until somebody ticks it.

Does it read my documents?

Yes, when Read the documents is on, and that is a switch he controls from the page. Word, PowerPoint and Excel are unzipped on the server and only the extracted text is sent; PDFs and images go whole, because a scan has no text to extract. With it off, it names from the file name, folder and kind alone.

Who else can get to this page?

Nobody without the passcode, and the webhook behind it needs a header key the browser never holds. A request without it is refused before anything runs.

Can it decide the folder structure itself?

It already has — the folders listed above were its proposal. It is bounded on purpose: a new folder has to hold at least two documents, no more than six new folders in a run, and it will never move anything in or out of a numbered stage folder, because those record how far the work has got and nothing about a document says which stage it belongs in.

What did it get wrong?

Be straight about this one. Where a document did not state its own date, the date came from the file timestamp, and where it did not state a status it was recorded as Draft. Both are disclosed on every proposal. The assumptions column above is the honest version of this answer.

If something goes wrong

  • The page sits there. A run takes about a minute. Say so before you press it, and it stops being a silence.
  • It says the run may still be going. It probably is. The workflow does not stop because the page stopped listening — wait, then press Look again. Do not press it twice.
  • It asks you to sign in again. The session lasts twelve hours. Type the passcode; nothing is lost.
  • Something is refused and he asks why. The refusal says why, in his words, on the page. Read it out rather than explaining around it.
  • Anything else. Failures are logged and alerted automatically. Say you will look at it after the call rather than debugging in front of him.

What not to say

Do not promise it finds every Power BI dependency.

It reads what is inside the file. A report published to the Power BI service, or set to refresh from a path, is referenced from outside the library, and nothing in the file or the folder shows that. Renaming the four reports was a decision, and the record above is what covers it.

Do not call it automatic.

Nothing is applied without a tick. That is the feature, and describing it as hands-off gives away the only guarantee he actually cares about.
