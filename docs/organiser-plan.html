Task Management Library Review

Every file in the Task Management library: what it is, whether it is in the right place, and what it is called. The names below were not pattern-matched out of the old ones — the documents were opened and read, and a model wrote a name for what each one actually holds. Nothing is left alone.

What is in the library

Every document typed by what is in it. Office files are unzipped on the server and only their text is sent; a PDF or a screenshot goes as itself, because a scan has no text layer and an image of a dashboard can only be read by looking at it. Power BI reports and the workbooks they feed are filtered out before anything is downloaded, so they are never opened at all. Reading a client's documents is a decision rather than something to slip into, and it is one switch: turn it off and the model sees only names and folders.

The convention, as he wrote it

[Project]_[Document Name]_[YYYY-MM-DD]_[Status]_v#.#

Statuses are Draft, Review, Final and Archived. Versions run v0.1–v0.3 for working drafts, v1.0 for the first approved version, v1.1 and up for minor approved updates, v2.0 for a major revision. Every rule below is checked on every file.

✓Dates written YYYY-MM-DD, so files sortAny other date shape is reported, and an eight-digit run is refused rather than guessed at.
✓Hyphens within a phrase, underscores between sectionsSpaces become hyphens inside a section; the sections themselves stay underscore-separated.
✓No spaces, no special charactersLetters, numbers, hyphens and underscores only.
✓Document name short but descriptiveA time of day is cut out — it says when a file was made, not what it holds. Where that leaves two files with one name, both are refused, because only a person can say what each one shows.
✓No Final_Final, Latest or NewThe version number is what says which one is current.
✓Keep the version number even when marked FinalAnd a Final numbered below v1.0 is reported, since an approved version starts at v1.0.
✓A project prefix where the document evidences oneThe format opens with a project, and a file name almost never carries it — but the document does. TCO, DIMP and Upperform below were read out of the contents and the folder path. Where nothing evidences a project, none is added and the proposal says so, because an invented project code is worse than none.

The folder structure it came up with

Not a template it filled in. It read the documents and said where each one belongs, and the rules below decided which of those groupings were allowed to exist. A new folder has to hold at least two documents — a folder holding one file is the pile it came from with an extra click in front — and one run proposes at most six. Each is created beside the documents that go in it, never as a reshuffle of the whole library.

Not renamed, and why

Nine documents used to sit here, every one of them refused because it resembled a Power BI report or shared its folder. The reports have since been opened and read — a .pbix is a ZIP, and its queries are inside it — and not one of them names any document in this library. The guessing is gone, and with it the refusals. Anything that does appear here is refused on evidence, with the reason written out in full rather than reduced to a code.

Where things sit

It moves almost nothing, and that is a finding rather than an omission. It will never move a Power BI report, a workbook a report reads, or anything inside a numbered stage folder — that last would be claiming how far a piece of work has got, which no file records and only you know. The one case it will act on is a document sitting above the filing with no folder of its own, and only where exactly one folder beside it says in its own name what it holds. There was one. It has been moved.

Why everything else stays put

What stops this going wrong

Off by default Renaming is switched off. A rename breaks every saved link, Teams tab and Power BI source pointing at the old name, so a person reads this page first.
Capped per run Even switched on, one run touches a handful of files — small enough to check by eye and undo by hand.
Never overwrites The move uses flags=0. If anything already sits on the new name the call fails rather than destroying it.
Never collides Two files that would land on the same name are both refused, not silently merged.
Never invents a status A status says whether a document is approved. Where the name doesn't carry one, the weakest — Draft — is assumed, and the assumption is shown.
Never guesses a date An eight-digit run like 04042025 is never read. Day-first and month-first disagree, and being right by luck is not being right.
Leaves Power BI alone A .pbix keeps the paths of the files it reads inside itself, where nothing outside can see them. Reports are never renamed in a sweep, and neither is a workbook sharing a report's folder or opening with a report's words.

What it can't know

It can read a Power BI report now, which it could not before. A .pbix is a ZIP: its Power Query text sits in one part, and where a report keeps its queries inside the model instead, the workbook's name is still somewhere in the bytes. So the question “does this report read that file?” is answered by asking the report rather than by noticing that two names look alike. All four were read, and none of them names a document in this library.

What it still cannot see is what lies outside the library. A report published to the Power BI service, or set to refresh from a path, is referenced from there, and nothing in the file or the folder shows it. Renaming the reports was therefore a decision rather than an inference — and the record above is what reverses it.

A status and a version are claims about approval, and a document usually does not state either. Where it does not, the weakest claim is assumed — Draft, v0.1 — and every proposal lists what was assumed rather than leaving you to notice.

Four of the files renamed above are workbooks. No report opens with their words or shares their folder, so nothing here suggests a dashboard reads them. If one of them is a source for something, its original name is in the list above and the rename takes seconds to put back.
