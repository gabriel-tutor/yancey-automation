What Yancey does

Opens the page at yancey-document-organiser.vercel.app and types the passcode. It lasts twelve hours. No n8n, no install, works on a phone.

Presses Look again. About a minute. It reads the library, opens the documents, and comes back with what it would change — and what it refuses to touch, with the reason.

Ticks what he agrees with and presses Carry it out. Nothing at all happens until he does. What he ticked is what gets applied, not what the model thinks a second time.

To point it at a different library, paste the SharePoint address straight from the browser bar into Which library to look at — the whole URL, exactly as it appears. The site and the library are read out of it, shown in the boxes, and used on the next Look again.

What it will not do

Each of these is a property of the code, not an instruction the model is asked to follow.

Change anything unasked

Every arming switch ships off. They are turned on by ticking a change and nothing else — a setting cannot arm a run.

Overwrite or collide

The call uses flags=0, so anything already on the new path fails rather than being destroyed. Two files that would land on one name are both refused.

Touch Power BI by default

It opens each .pbix and reads the Power Query inside to find which workbooks the report actually reads, then refuses those and quotes the query. One switch covers renaming and filing them.

Guess about stage folders

Nothing moves into or out of a numbered folder under any setting. Those record how far work has got, and no file knows that.

Invent

An invented project code is worse than none. Status defaults to Draft, the weakest claim, and every assumption is printed beside the change.

Leave the tenant

The host is fixed. Word, PowerPoint and Excel are opened on the server and only their text is sent; one setting turns reading off entirely.

Can you undo it?

Yes, and that is checkable rather than promised. All 29 documents the tool renamed trace back to the name they arrived under, in fixtures/sharepoint/renames-applied.json. A test reconciles that record against a measured listing of the library and fails on any chain that does not end where the file actually is.

Seven entries are marked reconstructed: they were applied and not written down at the time, and were worked out afterwards from the approved plan and the library. They carry their evidence, because an inferred line and a logged one are not the same thing and a reader deserves to know which they are looking at.

Running it after today

  • Change a setting Yancey can reach — the page. Reports in scope, reading documents, the change cap, folder limits, status when unstated, which library. All persist.
  • Change a rule — edit src/, run npm test, npm run emit, deploy to the sandbox, prove it there, then production. npm run verify gates it.
  • Check a deployment against the repo — npm run emit then npm run verify. Works for all ten workflows. It says when a difference is only the generated formatting, so red that matters is distinguishable from red that does not.
  • If a run seems stuck — it takes about a minute, and the workflow does not stop because the page stopped listening. Wait, then press Look again. Do not press it twice.
  • If something fails — it is logged, alerted, and the sandbox's failures go to the sandbox's handler, never the client's error log.

Worth doing next

An n8n API key. The single largest piece of manual handling left. Without one, deploying means reproducing node bodies by hand and then byte-checking the paste; with one, the repo could push and verify on its own. Two minutes in the n8n UI.

Two smaller things, both decisions rather than defects. Removing Mail.Send from the Entra app would turn the email agent's no-send property from verified into enforced — nothing reaches it today, but Microsoft would still accept one. And whether moving a Power BI report deserves its own switch, separate from renaming one: the code treats them as a single decision on purpose, because both change the path, and that is defensible — but it is Yancey's call, not a reading of a note.
